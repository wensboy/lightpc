# lightpc

A lightweight, thin-layer skeleton for quickly bootstrapping cross-platform applications. It helps you build a cross-platform desktop app rapidly through conventions, based on wails + web technology.

- Lightweight: Contains only the necessary thin-layer startup interfaces, with no complex design.
- Convention over configuration: Conventions guide development and design.
- Programmability: Friendly to secondary development and highly programmable.
- Decoupling: Strongly decoupled design.
